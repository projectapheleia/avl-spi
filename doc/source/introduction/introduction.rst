Welcome to AVL-SPI's Documentation
==================================

What is AVL?
------------

**AVL** is the Apheleia Verification Library.

For full details see `AVL Documentation <https://avl-core.readthedocs.io/en/latest/>`_.

What is SPI?
------------

**SPI** is the Serial Peripheral Interface, a synchronous, full duplex, serial bus between a single master and one or more slaves.

For full details see `SPI <https://en.wikipedia.org/wiki/Serial_Peripheral_Interface>`_.

Why Use AVL-SPI?
----------------

AVL-SPI is a library designed to simplify the verification of SPI-based designs using the AVL framework. \
It provides a set of tools and utilities that make it easier to write tests, manage transactions, and analyze results.

Most importantly AVL-SPI is designed to be easy and quick to integrate into your existing projects. \
It provides a simple mechanism to connect the AVL framework to your SPI designs, \
ensuring the VIP and design parameters are aligned.
