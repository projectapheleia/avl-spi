.. _coverage:

AVL-SPI Coverage
================

.. inheritance-diagram:: avl_spi._coverage
    :parts: 2


The :any:`Coverage <avl_spi._coverage.Coverage>` module is a passive component that hangs off the :any:`Monitor <avl_spi._monitor.Monitor>` item_export.

Each :any:`SequenceItem` generated by the monitor is sampled against the coverage model defined in the :any:`Coverage <avl_spi._coverage.Coverage>` class.

The user can extend the coverage model by extending the :any:`__init__ <avl_spi._coverage.Coverage.__init__>` method.

.. code-block:: python

    avl.Factory.set_variable("*.agent.cfg.has_coverage", True)
